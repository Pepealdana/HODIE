# HODIE — Validación de la Can-Do Matrix v1

## Estado

**FASE 1 — VALIDACIÓN PEDAGÓGICA Y ESTRUCTURAL: APROBADA CON AJUSTES**

La matriz queda preparada para pasar a la siguiente fase: **modelo de progreso y evidencia**.

La revisión se hizo contra tres referentes principales:

- **Council of Europe — CEFR / Companion Volume:** comprensión, producción oral y escrita, interacción, y control fonológico.
- **Cambridge English — B1 Preliminary:** Reading, Writing, Listening y Speaking; en Speaking se consideran Grammar & Vocabulary, Discourse Management, Pronunciation e Interactive Communication.
- **British Council — B1 Intermediate:** comprender los puntos principales de comunicación clara sobre temas familiares y producir comunicación oral y escrita sencilla y organizada.

HODIE sigue siendo un sistema **alineado** con estos referentes, no un sistema de certificación oficial.

## 2. Cobertura de competencias

La matriz ahora distingue tres capas:

### Competencias comunicativas

- Speaking / Spoken Production
- Listening / Listening Comprehension
- Reading / Reading Comprehension
- Writing / Written Production
- Written Interaction

### Interacción

- preguntas y respuestas
- pedir repetición
- pedir aclaración
- mantener conversaciones
- reaccionar a otros hablantes
- hacer seguimiento
- discrepar con cortesía
- negociar un acuerdo

### Recursos lingüísticos

- Grammar
- Vocabulary
- Pronunciation

La gramática, el vocabulario y la pronunciación **no son el objetivo final**: son recursos que deben aparecer al servicio de una tarea comunicativa.

## 3. Pronunciación: corrección importante

Se añadió una trayectoria específica de pronunciación porque no era correcto dejarla implícita dentro de Speaking.

HODIE ahora contempla:

- claridad e inteligibilidad
- acento de palabra
- acento de oración
- entonación básica
- inteligibilidad en discurso extendido

El objetivo B1 no es eliminar el acento español. Es conseguir que el habla sea generalmente inteligible y que el acento, ritmo y entonación no impidan la comunicación.

Esto coincide con el enfoque del CEFR sobre **phonological control** y con los criterios de Speaking de Cambridge.

## 4. Listening

La progresión queda:

**información personal → datos concretos → tema principal → detalles → explicaciones → conversaciones → entrevistas → opiniones/intención → conversación aunque no se comprenda cada palabra**

Se ajustó el descriptor B1 principal para hablar de **clear standard speech on familiar topics**, evitando exigir desde el inicio una comprensión de habla rápida o no controlada.

## 5. Reading

La progresión incluye:

- mensajes y textos breves
- instrucciones
- información específica
- textos personales
- textos profesionales
- textos técnicos sencillos
- idea principal
- detalles
- opinión
- inferencia por contexto
- textos conectados

Esto permite pasar de comprensión localizada a comprensión global e inferencial.

## 6. Writing

La progresión incluye producción y respuesta:

**información personal → mensajes → descripciones → experiencias → opiniones → textos conectados → mensajes profesionales → respuesta a emails/mensajes**

Se añadió explícitamente la capacidad de **responder a un mensaje o correo**, porque la interacción escrita no debe reducirse a producir textos desde cero.

## 7. Speaking

La progresión ya no depende solamente de hablar durante más tiempo.

Se trabajan:

- información personal
- familia y rutina
- experiencias
- trabajo
- proyectos
- procesos
- opiniones
- justificación
- problemas
- soluciones
- comparación
- planes y objetivos
- narración
- conversación
- seguimiento
- reparación de problemas comunicativos
- producción extendida

Esto permite acercarse a la naturaleza comunicativa del B1 descrita por CEFR, British Council y Cambridge.

## 8. Communication / Interactive Communication

Se reforzó especialmente esta área.

HODIE no debe enseñar solamente a producir frases correctas. Debe enseñar a **hacer cosas con el idioma**:

- iniciar
- responder
- preguntar
- pedir aclaración
- reaccionar
- continuar
- reformular
- discrepar
- sugerir
- negociar
- llegar a un acuerdo

Se añadió:

**CO-B1-07 — I can make and respond to suggestions and help reach an agreement.**

Esto conecta directamente con el tipo de interacción observado en Speaking B1 de Cambridge.

## 9. Vocabulary

Se mantiene la progresión:

**RECOGNIZE → UNDERSTAND → RECALL → USE → SPONTANEOUS USE**

Se corrigió un descriptor que intentaba medir directamente la traducción mental. El estado mental de "traducir o no traducir" puede servir como indicador de confianza o fluidez, pero no debe ser la única evidencia de competencia.

Ahora se evalúa algo observable:

**retrieval + use of familiar vocabulary in context**

## 10. Grammar

La gramática se mantiene como recurso comunicativo.

La ruta A2 → A2+ → B1 incluye, entre otros:

- be / have
- Present Simple
- Present Continuous
- there is / there are
- can / can't
- Past Simple
- future forms
- questions
- comparatives
- prepositions
- connectors
- Present Perfect
- contraste Present Perfect / Past Simple
- modals
- First Conditional
- relative clauses
- Past Continuous
- gerund / infinitive patterns
- basic passive

No se convertirá en una secuencia de "lecciones de gramática" independientes. El motor deberá introducirla cuando una tarea comunicativa muestre una necesidad.

## 11. A2+

HODIE conserva **A2+** como una zona interna de transición.

No se presentará al usuario como nivel oficial CEFR.

Su función es evitar el salto artificial:

**A2 → B1**

y representar el momento en que el estudiante empieza a conectar ideas, explicar experiencias, hablar de trabajo/proyectos, expresar opiniones y sostener interacciones más largas.

## 12. Evidencia y recuperación

Se detectó una debilidad importante en la versión anterior: muchos Can-Dos tenían prerrequisitos pero no una ruta de recuperación explícita.

La matriz ahora permite que el motor utilice los prerrequisitos del mismo dominio como puntos de recuperación cuando no existe una ruta específica.

Esto permite:

**fallo → identificar gap → volver al soporte adecuado → practicar → volver a intentar**

No se debe castigar al estudiante con más ejercicios aleatorios cuando falla.

## 13. Feedback

Se conserva el modelo bilingüe:

- interfaz: español inicialmente
- actividad: inglés
- producción: inglés
- explicación del error: inglés + español
- ejemplo corregido: inglés
- retry: inglés

La progresión prevista es:

- **A2:** bilingual-by-default
- **A2+:** English-first + Spanish support
- **B1:** English-first; Spanish cuando sea útil

La regla pedagógica es:

> Explicar en el idioma más fuerte del estudiante; demostrar y practicar la competencia en inglés.

## 14. Qué NO debe hacer HODIE

La validación establece límites para las siguientes fases:

- No convertir Grammar en el centro del sistema.
- No medir progreso solamente con porcentajes de respuestas correctas.
- No considerar vocabulario memorizado como vocabulario usable.
- No considerar una respuesta escrita correcta como prueba suficiente de Speaking.
- No considerar una prueba de Speaking como suficiente para Listening.
- No corregir todos los errores durante tareas de fluidez.
- No usar traducción mental como única medida.
- No presentar una puntuación interna como "certificación B1".
- No depender de una API de IA para que el sistema sea pedagógicamente funcional.

## 15. Punto pendiente para una fase posterior

El CEFR Companion Volume también incorpora **Mediation** como actividad comunicativa. No se añade todavía como una nueva carga obligatoria del núcleo A2→B1 porque el objetivo inmediato de HODIE es consolidar comprensión, producción e interacción.

Sin embargo, queda registrada como **extensión prevista**, especialmente útil para tareas como:

- explicar información a otra persona
- resumir un texto
- transmitir instrucciones
- explicar información de una gráfica o imagen
- reformular una idea con palabras propias
