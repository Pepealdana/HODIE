# HODIE Practice Architecture v2

## Objective

Separate what the learner wants to do, what capability is being trained, what language resource supports it, and how the learner interacts with the activity.

## Four layers

MODE
Mixed / Review
  ↓
FOCUS
Speaking / Listening / Reading / Writing / Communication
  ↓
RESOURCE
Grammar / Vocabulary / Pronunciation
  ↓
MICRO-ACTIVITY
Choose / Complete / Order / Match / Listening / Speak / Interaction / Production / Repair

A mode is not a skill. A resource is not a communicative outcome.

## Modes

### Mixed

Adaptive variety around the current learning target. It should normally include more than one communicative or resource type and avoid repeating the same mechanics unless the learner needs targeted reinforcement.

### Review

Evidence-driven recovery and retention. It reads recent errors, gaps, weak dimensions and retention state. It does not have a fixed content queue.

## Focus

### Speaking
Production, fluency, pronunciation and interaction.

### Listening
Gist, details, inference and response.

### Reading
Gist, details, inference and response.

### Writing
Task completion, clarity, coherence, grammar and vocabulary.

### Communication
Interaction, turn-taking, repair, clarification and successful response.

## Resources

### Grammar
A contextual support layer. Grammar activities must answer a communicative need and should normally lead back to production.

### Vocabulary
Recognition → recall → contextual use → spontaneous use → transfer.

### Pronunciation
Intelligibility first. Later iterations may add prosody and more advanced speech analysis.

## Activity roles

| Type | Primary function | Typical next step |
|---|---|---|
| choose | recognize | complete/use |
| complete | retrieve | produce |
| order | construct | produce |
| match | associate meaning | use |
| listening | understand speech | respond |
| speak | controlled production | guided production |
| interaction | exchange meaning | repair/transfer |
| mini-production | short demonstration | evidence |
| repair | correct a known gap | retry |
| reading | understand text | respond |
| writing | produce text | revise/transfer |

## Evidence boundary

Micro-activities may generate diagnostic signals. They do not directly mutate Can-Do mastery.

Authoritative progression remains:

practice → integrated demonstration → evidence boundary → learning engine

## Production evidence

A production task must declare observable criteria. Minimum characters may be a task aid but never the sole evidence of competence.

Example criteria:

- introduces self;
- states profession;
- gives one relevant detail;
- expresses one preference or experience.

## Confidence

Performance and confidence are separate dimensions.

A learner may perform adequately with low confidence. That evidence can establish functional performance while confidence remains a separate development target.

## Error handling

response
  ↓
evaluation
  ↓
structured errors
  ↓
priority selection
  ↓
feedback
  ↓
retry / variation / continue
  ↓
diagnostic history

The error history is useful for Review and adaptive planning.
